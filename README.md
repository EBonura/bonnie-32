> **BONNIE-32 is discontinued and no longer maintained.** The work has
> continued in **[PSoXide](https://github.com/EBonura/PSoXide)**, its
> spiritual successor.

## What this means

- **No new releases or bug fixes.** v0.1.12 is the final release. Source
  and binaries remain available indefinitely.
- **Active development continues in
  [PSoXide](https://github.com/EBonura/PSoXide)**, a spiritual successor
  built around a real PS1 emulator, a Rust SDK targeting `mipsel-sony-psx`,
  a runtime engine, an editor, and an asset pipeline for actual PS1
  hardware.
- The source code stays here. Forks are welcome.

## What BONNIE-32 was

A fantasy console for making PS1-era 3D games on modern hardware:
software rasterizer recreating affine textures / vertex snapping /
RGB555, integrated low-poly modeler, world editor, and music tracker
with hardware-accurate PS1 SPU emulation. Built in Rust; native + WASM
web build.

## Where BONNIE-32 still lives

- **Final release**:
  [v0.1.12](https://github.com/EBonura/bonnie-32/releases/tag/v0.1.12)
  binaries (Windows, macOS, Linux).
- **Source**: this repository, MIT-licensed. Fork freely.
- **PSoXide** (active): https://github.com/EBonura/PSoXide

## Final state at deprecation

- Latest release: v0.1.12 (2026-03-15).
- v2 rewrite reached Phase 4 on the `v2` branch and is left in place
  for reference; it was not released and is unsupported.
- Open issues are closed with this same redirect.
